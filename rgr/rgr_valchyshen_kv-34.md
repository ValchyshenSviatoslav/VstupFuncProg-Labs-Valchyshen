## Постановка задачі конкретного варіанту

**Варіант №2**

Обчислити значення послідовності $F_i$ за наступними правилами:

$$F_1 = 1, \quad F_{16} = 2$$
$$F_i = \begin{cases} F_{i-1} \cdot 2 + 5 \sin(i), & i = 2 \dots 15 \\ F_{i-1} / 2 + 5 \cos(i), & i = 17 \dots 30 \end{cases}$$

## Реалізація програми мовою Common Lisp

```lisp
(defun calc-f (i)
  (cond
    ((= i 1) 1)
    ((and (>= i 2) (<= i 15))
     (+ (* (calc-f (1- i)) 2) (* 5 (sin i))))
    ((= i 16) 2)
    ((and (>= i 17) (<= i 30))
     (+ (/ (calc-f (1- i)) 2.0) (* 5 (cos i))))
    (t (error "Index out of bounds (1-30)"))))
```

## Реалізація тестових утиліт і тестових наборів

```lisp
(defun check-calc-f (name i expected)
  (let* ((actual (calc-f i))
         (passed (<= (abs (- actual expected)) 0.001)))
    (format t "~:[FAILED~;passed~]... ~a (expected ~a, got ~a)~%" 
            passed name expected actual)))

(defun test-calc-f ()
  (check-calc-f "test F(1)  - Base case 1" 1 1)
  (check-calc-f "test F(2)  - Sequence 2..15" 2 6.546487)
  (check-calc-f "test F(3)  - Sequence 2..15" 3 13.79857)
  (check-calc-f "test F(16) - Base case 2" 16 2)
  (check-calc-f "test F(17) - Sequence 17..30" 17 -0.375816))
```

## Порівняння результатів з обчисленням іншими програмними засобами

Для перевірки достовірності розрахунків, виконаних мовою Common Lisp, було проведено паралельні обчислення за допомогою мови програмування **Python** (модуль `math`) та звичайного інженерного калькулятора.

**Ручний розрахунок (інженерний калькулятор):**
* Значення $F_2 = F_1 \cdot 2 + 5 \sin(2) = 1 \cdot 2 + 5 \cdot 0.909297 = 2 + 4.546485 = 6.546485$
* Значення $F_{17} = F_{16} / 2 + 5 \cos(17) = 2 / 2 + 5 \cdot (-0.275163) = 1 - 1.375815 = -0.375815$

**Код для перевірки на Python:**
```python
import math

def calc_f(i):
    if i == 1:
        return 1
    elif 2 <= i <= 15:
        return calc_f(i - 1) * 2 + 5 * math.sin(i)
    elif i == 16:
        return 2
    elif 17 <= i <= 30:
        return calc_f(i - 1) / 2 + 5 * math.cos(i)

print(f"F(2)  = {calc_f(2):.6f}")
print(f"F(17) = {calc_f(17):.6f}")
```

**Вивід Python-скрипта:**
```text
F(2)  = 6.546487
F(17) = -0.375817
```

**Висновок:** 
Значення, отримані за допомогою програми мовою Common Lisp ($F_2 \approx 6.546487$, $F_{17} \approx -0.375816$), з високою точністю збігаються з результатами обчислень на Python та інженерному калькуляторі.
